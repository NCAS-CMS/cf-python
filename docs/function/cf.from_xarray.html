cf.from_xarray¶

cf.from_xarray(ds, domain=False)[source]¶

Convert an xarray dataset to CF field or domain constructs.

In general (see the note below) cf.from_xarray is an in-memory operation which does two things: it maps the xarray dataset variables and attributes onto CF constructs; and it copies pointers to the arrays describing the actual data, from the xarray dataset to the fields or domains. No actual data is copied.

cf.from_xarray treats the xarray dataset as if it were an in-memory view of a netCDF dataset (even if it wasn’t created as such), and creates the same CF field or domain constructs that cf.read would if it were to read that netCDF dataset.

Warning

For optimal performance and minimal memory usage, open xarray datasets from disk with decode_cf=False. This is not the default for xarray.open_dataset or xarray.open_datatree.

If the dataset is opened with the default decode_cf=True, the automatic reversal of xarray’s CF decoding for selected variables will eagerly load their data arrays into memory. This applies to variables with explicit _FillValue or missing_value attributes, and to variables decoded into non-numeric time or timedelta objects.

This is never an issue for datasets created with cf.to_xarray: cf.from_xarray(cf.to_xarray(f)) will never load those data arrays into memory.

Added in version 1.13.4.0.

See also

cf.to_xarray, cf.read

Parameters:
ds: xarray.Dataset or xarray.DataTree

The xarray dataset to be converted. The group structure of an xarray.DataTree instance is preserved in the returned field or domains.

domain: bool, optional

If False (the default) then return only field constructs that are defined by CF data variables in the xarray dataset, ignoring all CF domain variables. If True then only the domain constructs that are explicitly defined by CF domain variables in the xarray dataset are returned.

Returns:
sequence of Field or Domain

The equivalent fields or domains.

Examples:

Create some field constructs, convert them to an xarray dataset, convert the xarray dataset back to field constructs, and show that (in this case) no information has been lost.

>>> f = cf.example_fields(0, 7)
>>> f

 <CF Field: eastward_wind(time(3), air_pressure(1), grid_latitude(4), grid_longitude(5)) m s-1>]
