cf.to_iris¶

cf.to_iris(f)[source]¶

Convert CF field constructs to iris cubes.

cf.to_iris is an in-memory operation which does two things: it maps the CF constructs onto iris cubes; and it copies pointers to the arrays describing the actual data, from the fields to the iris cubes. No actual data is copied.

Method:

The conversion is a three-step process: CF fields are mapped to an xarray dataset, which is mapped to an ncdata.NcData dataset-level container, which is mapped to iris cubes. I.e. c = cf.to_iris(f) is exactly equivalent to:

>>> from ncdata.xarray import from_xarray as ncdata_from_xarray
>>> from ncdata.iris import to_iris as ncdata_to_iris
>>> ds = cf.to_xarray(f)
>>> n = ncdata_from_xarray(ds)
>>> c = ncdata_to_iris(n)

Added in version 1.13.4.0.

See also

cf.from_iris, cf.to_xarray, cf.from_xarray

Parameters:
f: (sequence of) Field

The CF fields to be converted.

Returns:
iris.cube.CubeList

The equivalent iris.cube.Cube objects.

Examples:

Create some field constructs, convert them to iris cubes, and convert the iris cubes back to field constructs.

>>> f = cf.example_fields(0, 7)
>>> f
[<CF Field: specific_humidity(latitude(5), longitude(8)) 1>,
 <CF Field: eastward_wind(time(3), air_pressure(1), grid_latitude(4), grid_longitude(5)) m s-1>]
>>> c = cf.to_iris(f)
>>> c
[<iris 'Cube' of eastward_wind / (m s-1) (time: 3; air_pressure: 1; grid_latitude: 4; grid_longitude: 5)>,
<iris 'Cube' of specific_humidity / (1) (latitude: 5; longitude: 8)>]
>>> g = cf.from_iris(c)
>>> g
[<CF Field: specific_humidity(latitude(5), longitude(8)) 1>,
 <CF Field: eastward_wind(time(3), air_pressure(1), grid_latitude(4), grid_longitude(5)) m s-1>]
