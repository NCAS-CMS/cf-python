cf.to_xarray¶

cf.to_xarray(f, group=True)[source]¶

Convert CF field or domain constructs to an xarray dataset.

cf.to_xarray is an in-memory operation which does two things: it maps the CF constructs onto xarray dataset variables and attributes; and it copies pointers to the arrays describing the actual data, from the fields or domains to the xarray dataset. No actual data is copied.

In general, cf.to_xarray creates an xarray dataset that is an in-memory view of the netCDF dataset that would have been created by writing the CF field or domain constructs to disk with cf.write.

Tip

A very convenient way to access uncompressed CF data in an xarray dataset

When cf.read reads fields and domains from datasets with CF compression-by-convention features (discrete sampling geometries, cell geometries, coordinate subsampling, gathering, etc.), these are represented as uncompressed views of the data stored in lazy Dask arrays. Because these Dask arrays are passed on unchanged to an xarray dataset, cf.read and cf.to_xarray together provide a means to directly access uncompressed CF data in xarray:

>>> f = cf.read(<datasets>)
>>> ds = cf.to_xarray(f)

Tip

Integration with cf_xarray

If the cf_xarray package (https://cf-xarray.readthedocs.io) is installed then the cf_xarray accessors that allow some interpretation of CF attributes will be present on the xarray dataset.

Added in version 1.13.4.0.

See also

cf.from_xarray, cf.write

Parameters:
f: (sequence of) Field or Domain

The fields or domains to be converted.

group: bool, optional

If False then create a “flat” xarray dataset, i.e. one with only the root group, regardless of any group structure specified by the netCDF interfaces of the fields, domains, or their components. If True (the default) then any sub-groups will be created and populated.

Returns:
xarray.Dataset or xarray.DataTree

The equivalent xarray dataset.

If there are no sub-groups of the root group, or if group is False, then an xarray.Dataset is returned.

If there are sub-groups of the root group and group is True, then an xarray.DataTree is returned.

Examples:

Create some field constructs, convert them to an xarray dataset, convert the xarray dataset back to field constructs, and show that (in this case) no information has been lost.
