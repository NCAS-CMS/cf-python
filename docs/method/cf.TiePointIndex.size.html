cf.TiePointIndex.size¶

TiePointIndex.size()¶

The number elements in the data.

size is equal to the product of shape, that only includes the sizes of dimensions that correspond to domain axis constructs.

See also

data, has_data, ndim, shape

Examples

>>> f.shape
(73, 96)
>>> f.ndim
2
>>> f.size
7008

>>> f.shape
(73, 1, 96)
>>> f.ndim
3
>>> f.size
7008

>>> f.shape
(73,)
>>> f.ndim
1
>>> f.size
73

>>> f.shape
()
>>> f.ndim
0
>>> f.size
1
